Automatic data connection

Provider adapter required

Automatic mode requires a licensed football data / odds API or your own secure adapter. This app does not scrape SportyBet or contain a built-in data subscription.

Expected adapter response

The fixtures endpoint should return JSON in this shape. Statistics and odds responses should include their source, timestamp and market definition.
{ "fixtures": [ { "id": "match-id", "league": "Premier League", "home": "Home FC", "away": "Away FC", "kickoff": "2026-11-20T19:00:00Z" } ] }
Never place a private provider master key in a public APK. For production automatic feeds, use a secure backend proxy with rate limits and provider credentials stored server-side.

Import calibration profile

Profiles map raw model probabilities to observed out-of-sample probabilities. Import a separate profile for each league.

Imported profiles are user-supplied and are not independently audited by this app. A profile must cover the probability range being evaluated.

Responsible use

This app is an analytical tool, not a guarantee of profit. Betting can cause financial loss. Never borrow, chase losses or stake money needed for essentials. A NO BET result is a valid result.
